# Trivia Challenge ⚡

A fast, vanilla JavaScript trivia app with dynamic categories, countdown timer and auto-progress. Built from scratch with ES6 modules and powered by the Open Trivia Database API.

Live Demo: https://richchidi.github.io/js-quiz-app/

### Features
- 🌐 Dynamic categories and questions via Open Trivia DB API
- ⏱️ 15s countdown per question with auto-move to next question
- 🔴 Red low-time warning when time <= 5s
- 📊 Animated progress bar with `overflow: hidden` clipping
- 🧩 Modular architecture: `home-screen.js`, `quiz-screen.js`, `result-screen.js`, `quiz-data.js`
- 🏆 High score saved with localStorage + percentage score
- 📱 Responsive design

### Tech Stack
- HTML5 / CSS3 / Vanilla JS (ES Modules)
- Open Trivia DB API - https://opentdb.com/
- No frameworks - pure logic
