# JS Quiz App ⚡️

A fast, vanilla JavaScript quiz app with a countdown timer and auto-progress. Built from scratch and refactored into ES6 modules.

Live Demo:  https://richchidi.github.io/js-quiz-app/

### Features
- ⏱️ 15s countdown per question with auto-move to next question
- 🔴 Red low-time warning when time <= 5s
- 📊 Animated progress bar with `overflow: hidden` clipping
- 🧩 Modular architecture: `home-screen.js`, `quiz-screen.js`, `result-screen.js`, `quiz-data.js`
- 💾 High score saved with localStorage
- 📱 Responsive design

### Tech Stack
- HTML5 / CSS3 / Vanilla JS (ES Modules)
- No frameworks — pure logic
